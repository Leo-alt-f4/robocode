## Sobre o robô vindo dos infernos

 Bem, o propósito base dele, era ser um tracker, no qual ficaria rondando ao redor do robô para atirar e girar.

 Para colocar este robô no sistema, use o `robocode`, vá no editor dele e abra o arquivo do robô. 
 Após isso, `'compile'` o arquivo e salve em uma pasta do robocode.

 Este robô em si tem os comentários de como funciona dentro dele e não precisa de muitas explicações para rodar ele.

 *OBS.:* em um dos commits antigos (talvez o primeiro) ele possuía um arquivo `.class`, esse arquivo é o robô compilado
 só precisa fazer as funções mencionadas anteriormente e tá de boas, então não é necessário colocar ele (a `.class`) aq.
